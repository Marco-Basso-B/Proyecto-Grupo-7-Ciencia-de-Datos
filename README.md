# Proyecto-Grupo-7-Ciencia-de-Datos
El Proyecto consiste en crear un código que permita filtrar desde una base de datos las Leyes de Cobre para un flujo de interes de la Planta Concentradora de una Minera, verificar los análisis que se hallan realizado en duplicado y constatar si la precisión establecida para la metodología cumple el criterio de Calidad.
